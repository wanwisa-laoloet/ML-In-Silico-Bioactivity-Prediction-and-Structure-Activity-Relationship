## บทคัดย่อ

กระบวนการค้นหาและพัฒนายาใหม่เผชิญข้อจำกัดด้านระยะเวลาและต้นทุนมหาศาล การทดสอบฤทธิ์ทางชีวภาพของสารเคมีในห้องปฏิบัติการจริงกับโปรตีนเป้าหมาย เช่น เอนไซม์ Main Protease (M^pro หรือ 3CL^pro) ของเชื้อไวรัส SARS-CoV-2 มีขั้นตอนซับซ้อนและมีค่าใช้จ่ายสูง โครงงานนี้จึงพัฒนาแบบจำลองการเรียนรู้ของเครื่องเพื่อทำนายค่าความสามารถในการยับยั้งเอนไซม์ในรูป pIC50 แบบ In Silico

คณะผู้จัดทำรวบรวมข้อมูลจากฐานข้อมูล ChEMBL เป้าหมาย `CHEMBL4523582` จำนวน 4,867 รายการ กรองเฉพาะ assay ที่วัด 3CL-Pro เหลือ 2,889 รายการ และผ่านกระบวนการทำความสะอาด 13 ขั้นตอน ได้ชุดข้อมูลมาตรฐาน 2,198 โมเลกุลที่ไม่ซ้ำกัน สกัดคุณลักษณะแบบผสม (Hybrid Features) จำนวน 1,028 มิติ ประกอบด้วย Morgan Fingerprints (ECFP4, รัศมี 2, 1,024 บิต) และ Lipinski Descriptors 4 ตัว จากนั้นเปรียบเทียบแบบจำลอง 4 ชนิด ได้แก่ Dummy Regressor, Random Forest, XGBoost และ Support Vector Regressor ผ่าน Scikit-learn Pipeline ที่ป้องกันการรั่วไหลของข้อมูล พร้อมทำ 5-Fold Cross-Validation และปรับจูนไฮเปอร์พารามิเตอร์

ผลการทดลองพบว่า XGBoost ให้ประสิทธิภาพสูงสุดบนชุดทดสอบ โดยมีค่า R² = 0.7034, RMSE = 0.5487, MAE = 0.3918 และ Spearman ρ = 0.8415 ซึ่งเหนือกว่าแบบจำลองพื้นฐานอย่างมีนัยสำคัญ (R² = −0.0000) การทำนายร้อยละ 93.6 มีความคลาดเคลื่อนไม่เกิน 1 log unit เมื่อทดสอบด้วยการแบ่งข้อมูลตามโครงสร้างแกนกลาง (Scaffold Split) ค่า R² ลดลงเหลือ 0.5127 ซึ่งสะท้อนความสามารถทำนายที่แท้จริงเมื่อพบสารแกนโครงสร้างใหม่

การวิเคราะห์ด้วยเทคนิค SHAP พบว่าน้ำหนักโมเลกุลเป็นคุณลักษณะสำคัญที่สุด (Mean|SHAP| = 0.1165) และสามารถระบุโครงสร้างย่อย 2 มิติที่สัมพันธ์กับการเพิ่มและลดฤทธิ์ยับยั้งได้ 6 บิต โดยบิตที่ 301 พบในสารกลุ่ม active ร้อยละ 50.9 แต่พบในกลุ่ม inactive เพียงร้อยละ 13.1

ข้อค้นพบที่สำคัญคือ การทดสอบข้ามชุดข้อมูลกับสาร COVID-19 จากแหล่งอิสระ 90 ตัว ให้ค่า R² = −1.72 ซึ่งแย่กว่าการทำนายด้วยค่าเฉลี่ย สาเหตุมาจากร้อยละ 84.4 ของสารกลุ่มดังกล่าวอยู่นอกขอบเขตการใช้งานของแบบจำลอง (Applicability Domain) ผลนี้ชี้ว่าแบบจำลอง QSAR ที่มีค่า R² สูงบนชุดทดสอบภายในไม่ได้รับประกันความสามารถทำนายสารนอกปริภูมิเคมีเดิม

## Abstract

Drug discovery is constrained by substantial time and cost requirements. Experimental determination of compound bioactivity against protein targets such as the SARS-CoV-2 Main Protease (M^pro/3CL^pro) is laborious and expensive. This project develops machine learning models to predict enzyme inhibition potency (pIC50) in silico.

Bioactivity data were retrieved from ChEMBL target `CHEMBL4523582`, yielding 4,867 IC50 records. Assay-level filtering for 3CL-Pro retained 2,889 records, and a 13-step cleaning protocol produced a curated dataset of 2,198 unique molecules. Hybrid features comprising 1,024-bit Morgan fingerprints (ECFP4, radius 2) and four Lipinski descriptors (1,028 dimensions total) were extracted. Four regressors — Dummy, Random Forest, XGBoost and Support Vector Regressor — were compared within a leakage-safe Scikit-learn Pipeline using 5-fold cross-validation and hyperparameter tuning.

XGBoost achieved the best held-out performance (R² = 0.7034, RMSE = 0.5487, MAE = 0.3918, Spearman ρ = 0.8415), substantially exceeding the baseline (R² = −0.0000); 93.6% of predictions fell within one log unit. Under a Bemis–Murcko scaffold split, R² decreased to 0.5127, providing a more realistic estimate of prospective performance.

SHAP analysis identified molecular weight as the most influential feature (Mean|SHAP| = 0.1165) and mapped six fingerprint bits to interpretable 2D substructures; bit 301 occurred in 50.9% of active compounds versus 13.1% of inactives.

Critically, external validation on 90 independent COVID-19 compounds yielded R² = −1.72, worse than mean prediction, because 84.4% of these compounds fell outside the model's applicability domain. This demonstrates that high internal test performance in QSAR does not guarantee generalisation beyond the training chemical space.

**Keywords:** Machine Learning, QSAR, SARS-CoV-2 Main Protease, pIC50, Morgan Fingerprints, SHAP, Applicability Domain

# บทที่ 1 บทนำ

## 1.1 ความเป็นมาและความสำคัญของปัญหา

กระบวนการค้นหาและพัฒนายาใหม่ (Drug Discovery) ในปัจจุบันต้องเผชิญกับข้อจำกัดด้านระยะเวลาและต้นทุนมหาศาล การนำยาหนึ่งชนิดออกสู่ตลาดใช้เวลาเฉลี่ย 10–15 ปี และมีค่าใช้จ่ายหลายพันล้านบาท ขั้นตอนที่เป็นคอขวดสำคัญคือการคัดกรองสารเคมีจำนวนมหาศาลเพื่อหาสารที่มีศักยภาพ ซึ่งการทดสอบฤทธิ์ทางชีวภาพในห้องปฏิบัติการจริง (Wet Lab Experiment) กับโปรตีนเป้าหมายมีขั้นตอนที่ซับซ้อนและมีค่าใช้จ่ายสูง

เชื้อไวรัส SARS-CoV-2 ซึ่งเป็นสาเหตุของโรค COVID-19 มีเอนไซม์ Main Protease (M^pro หรือเรียกอีกชื่อว่า 3CL^pro) เป็นเอนไซม์ชนิดซิสเตอีนโปรตีเอส (Cysteine Protease) ที่มีบทบาทสำคัญยิ่งในวงจรชีวิตของไวรัส เอนไซม์นี้ทำหน้าที่ตัดสายพอลิโปรตีนที่ไวรัสสร้างขึ้นให้กลายเป็นโปรตีนย่อยที่ทำงานได้ (Non-structural Proteins) ซึ่งจำเป็นต่อการเพิ่มจำนวนของไวรัส การยับยั้งการทำงานของ M^pro จึงสามารถหยุดยั้งกระบวนการแบ่งตัวของไวรัสได้โดยตรง และเนื่องจากมนุษย์ไม่มีเอนไซม์ที่มีความคล้ายคลึงกับ M^pro ทำให้เอนไซม์นี้เป็นเป้าหมายยาที่น่าสนใจอย่างยิ่งเพราะมีโอกาสเกิดผลข้างเคียงต่อเซลล์มนุษย์ต่ำ

การพัฒนาวิธีการคำนวณทางคอมพิวเตอร์แบบจำลองในคอมพิวเตอร์ (In Silico) จึงเข้ามามีบทบาทสำคัญในการคัดกรองและประเมินประสิทธิภาพสารเคมีเบื้องต้นก่อนนำไปทดสอบจริง แนวทางหนึ่งที่ได้รับการยอมรับคือการศึกษาความสัมพันธ์เชิงปริมาณระหว่างโครงสร้างทางเคมีกับการออกฤทธิ์ทางชีวภาพ (Quantitative Structure-Activity Relationship: QSAR) ซึ่งในทางวิทยาการข้อมูลถือเป็นโจทย์ปัญหาประเภทการถดถอย (Regression Problem) โดยมีเป้าหมายเพื่อทำนายค่าความสามารถในการยับยั้งเอนไซม์ ซึ่งวัดจากค่าความเข้มข้นที่ยับยั้งการทำงานได้ครึ่งหนึ่ง (Half Maximal Inhibitory Concentration: IC50) ในหน่วยนาโนโมลาร์ (nM) และแปลงให้อยู่ในรูปตัวแปรต่อเนื่องที่มีการกระจายตัวแบบสมมาตร (pIC50)

การทำนายฤทธิ์สารเคมีอย่างมีประสิทธิภาพจำเป็นต้องอาศัยการสกัดคุณลักษณะ (Feature Extraction) จากโครงสร้างโมเลกุลในรูปแบบ SMILES ประกอบด้วยคุณลักษณะเชิงโครงสร้างย่อย 2 มิติ (Morgan Fingerprints / ECFP4) และคุณสมบัติทางกายภาพเคมีตามกฎของลิพินสกี (Lipinski's Descriptors) ได้แก่ น้ำหนักโมเลกุล ค่าสัมประสิทธิ์การละลาย จำนวนอะตอมผู้ให้อิเล็กตรอน และจำนวนอะตอมผู้รับอิเล็กตรอน มาประกอบเป็นชุดคุณลักษณะแบบผสม (Hybrid Features)

นอกจากนี้ ปัญหาสำคัญที่พบบ่อยในงาน QSAR คือการรั่วไหลของข้อมูล (Data Leakage) ระหว่างการปรับสเกลข้อมูลกับกระบวนการตรวจสอบความถูกต้องข้ามกลุ่ม (Cross-Validation) ซึ่งทำให้ผลลัพธ์ที่รายงานสูงเกินจริง โครงงานนี้จึงประยุกต์ใช้ Scikit-learn Pipeline ในการผนวกขั้นตอนการปรับมาตรฐานข้อมูลเข้ากับแบบจำลอง และใช้เทคนิคปัญญาประดิษฐ์ที่อธิบายได้ (Explainable AI: SHAP) เพื่อวิเคราะห์ความสำคัญของคุณลักษณะโครงสร้าง พร้อมทำการจับคู่ย้อนกลับ (Bit Mapping) เป็นภาพโครงสร้างย่อย 2 มิติ เพื่ออธิบายความสัมพันธ์ระหว่างโครงสร้างโมเลกุลกับฤทธิ์การยับยั้งเอนไซม์ได้อย่างโปร่งใสและตรวจสอบได้

## 1.2 วัตถุประสงค์ของโครงงาน

1. เพื่อพัฒนาและเปรียบเทียบประสิทธิภาพของแบบจำลองการเรียนรู้ของเครื่อง (Machine Learning) ในการทำนายค่าฤทธิ์การยับยั้งเอนไซม์ SARS-CoV-2 Main Protease (pIC50) แบบ In Silico
2. เพื่อสร้างกระบวนการเตรียมและสกัดคุณลักษณะโมเลกุลแบบผสม (Hybrid Features) จาก Morgan Fingerprints และ Lipinski Descriptors ผ่าน Scikit-learn Pipeline ที่ป้องกันการรั่วไหลของข้อมูล (Data Leakage)
3. เพื่อวิเคราะห์และอธิบายความสัมพันธ์ระหว่างคุณลักษณะทางโครงสร้างกับฤทธิ์ทางชีวภาพ (SAR Analysis) โดยใช้เทคนิค Explainable AI (SHAP) ร่วมกับการสกัดภาพโครงสร้างโมเลกุลย่อย 2 มิติ

## 1.3 ขอบเขตของโครงงาน

1. มุ่งเน้นศึกษาเฉพาะสารยับยั้งเอนไซม์ Main Protease (M^pro) ของเชื้อไวรัส SARS-CoV-2 โดยใช้ข้อมูลจากฐานข้อมูล ChEMBL
2. ใช้ค่า IC50 ที่มีหน่วยการวัดเป็นนาโนโมลาร์ (nM) เท่านั้น และแปลงเป็น pIC50 สำหรับการสร้างแบบจำลองประเภทการถดถอย
3. สกัดคุณลักษณะโมเลกุลแบบ 2 มิติ ได้แก่ Morgan Fingerprints ขนาด 1,024 บิต และ Lipinski Descriptors 4 ค่า รวมเป็น 1,028 คุณลักษณะ
4. เปรียบเทียบแบบจำลองการเรียนรู้ของเครื่อง 4 ชนิด ได้แก่ Dummy Regressor (Baseline), Random Forest, XGBoost และ Support Vector Regressor (SVR)
5. ประเมินประสิทธิภาพด้วยตัวชี้วัด R², RMSE และ MAE ร่วมกับการทำ 5-Fold Cross Validation

## 1.4 ข้อจำกัดของโครงงาน

1. การศึกษานี้เป็นการจำลองและวิเคราะห์ทางคอมพิวเตอร์ (In Silico) เท่านั้น ไม่ได้มีการทดสอบยืนยันในห้องปฏิบัติการจริง (In Vitro Validation)
2. การวิเคราะห์ SAR ผ่าน SHAP เป็นการระบุ **ความสัมพันธ์เชิงสถิติ (Statistical Association)** ระหว่างชิ้นส่วนโมเลกุลกับการทำนายของแบบจำลอง ไม่สามารถอ้างเป็นกลไกการจับทางชีวภาพเชิงสาเหตุระดับอะตอม 3 มิติ (Causal Mechanism) ได้
3. ไม่ครอบคลุมการคำนวณพลศาสตร์โมเลกุล 3 มิติ (Molecular Dynamics) หรือการจำลองการจับตัวของลิแกนด์กับโปรตีน (Molecular Docking)

## 1.5 ประโยชน์ที่คาดว่าจะได้รับ

1. ได้แบบจำลองการเรียนรู้ของเครื่องที่มีความแม่นยำและปราศจากปัญหา Data Leakage สำหรับทำนายค่าฤทธิ์การยับยั้งเอนไซม์ SARS-CoV-2 Main Protease (pIC50) เบื้องต้นได้อย่างรวดเร็ว
2. ทราบถึงคุณลักษณะทางโครงสร้างย่อย 2 มิติ (Substructures) และคุณสมบัติทางเคมีกายภาพที่มีความสัมพันธ์ต่อระดับการออกฤทธิ์ยับยั้งเอนไซม์ ซึ่งสามารถใช้เป็นแนวทางชี้นำสำหรับนักเคมียาในการออกแบบโมเลกุลตัวยาใหม่
3. ได้ชุดข้อมูลโครงสร้างโมเลกุลมาตรฐานที่ผ่านการทำความสะอาดและสกัดคุณลักษณะแล้ว (`clean_bioactivity_master.csv`) เพื่อนำไปต่อยอดในงานวิจัยด้านเคมีสารสนเทศ (Cheminformatics) และการพัฒนาเว็บแอปพลิเคชันคัดกรองตัวยาในอนาคต

# บทที่ 2 ทฤษฎีและงานวิจัยที่เกี่ยวข้อง

## 2.1 เอนไซม์เป้าหมายและค่าฤทธิ์ทางชีวภาพ

### 2.1.1 SARS-CoV-2 Main Protease

เอนไซม์ SARS-CoV-2 Main Protease (M^pro) เป็นเอนไซม์ชนิดซิสเตอีนโปรตีเอสที่เข้ารหัสอยู่ในบริเวณ nsp5 ของ Replicase Polyprotein 1ab เอนไซม์นี้ทำงานในรูปไดเมอร์ (Dimer) และมีตำแหน่งเร่งปฏิกิริยา (Catalytic Dyad) ประกอบด้วยกรดอะมิโนฮิสทิดีนที่ตำแหน่ง 41 และซิสเตอีนที่ตำแหน่ง 145

หน้าที่หลักของ M^pro คือการตัดสายพอลิโปรตีน pp1a และ pp1ab ที่ไวรัสสร้างขึ้นให้กลายเป็นโปรตีนย่อยที่ทำงานได้ โดย M^pro รับผิดชอบการตัดอย่างน้อย 11 ตำแหน่ง การยับยั้งเอนไซม์นี้จึงหยุดกระบวนการเพิ่มจำนวนของไวรัสได้โดยตรง Jin และคณะ (2020) ได้รายงานโครงสร้างผลึกของ M^pro พร้อมการค้นพบสารยับยั้ง ซึ่งเป็นงานพื้นฐานสำคัญที่กระตุ้นการวิจัยสารยับยั้ง M^pro อย่างกว้างขวาง

ความสำคัญเชิงเภสัชวิทยาของ M^pro อยู่ที่การที่มนุษย์ไม่มีเอนไซม์ที่มีความคล้ายคลึงเชิงโครงสร้างและหน้าที่ ทำให้สารยับยั้งที่ออกแบบมาจำเพาะต่อ M^pro มีโอกาสเกิดพิษต่อเซลล์เจ้าบ้านต่ำ ตัวอย่างยาที่พัฒนาสำเร็จบนหลักการนี้คือ Nirmatrelvir ซึ่งเป็นองค์ประกอบหลักของยา Paxlovid

### 2.1.2 ค่า IC50 และการแปลงเป็น pIC50

ค่า IC50 (Half Maximal Inhibitory Concentration) เป็นตัวชี้วัดความเข้มข้นของสารที่ใช้ยับยั้งการทำงานของเอนไซม์ได้ร้อยละ 50 ข้อมูลในฐานข้อมูล ChEMBL ถูกจัดเก็บในหน่วยนาโนโมลาร์ (nM) และมีการกระจายตัวแบบเบ้ขวาอย่างรุนแรง (Right-skewed) เนื่องจากค่าครอบคลุมหลายลำดับขนาด

การแปลงเป็นค่า pIC50 ช่วยลดความเบ้ของข้อมูลและทำให้ตัวแปรตามมีการกระจายตัวใกล้เคียงปกติ ซึ่งเหมาะสมกับการสร้างแบบจำลองการถดถอย โดยมีความสัมพันธ์ทางคณิตศาสตร์ดังนี้

$$\text{pIC50} = -\log_{10}(\text{IC50}[\text{M}]) = 9 - \log_{10}(\text{IC50}[\text{nM}])$$

ตัวอย่างเช่น สารที่มี IC50 = 100 nM จะมี pIC50 = 9 − log₁₀(100) = 9 − 2 = 7.0 ค่า pIC50 ที่สูงกว่าหมายถึงสารมีฤทธิ์แรงกว่า

**ข้อควรระวังเรื่องหน่วย** ในบางแหล่งข้อมูลค่า pIC50 ถูกคำนวณบนฐานหน่วยไมโครโมลาร์ (µM) ซึ่งจะมีความสัมพันธ์ pIC50(µM basis) = pIC50(มาตรฐาน) − 6 การนำข้อมูลจากต่างแหล่งมารวมกันจึงต้องตรวจสอบหน่วยฐานให้ตรงกันก่อนเสมอ

## 2.2 การแทนรหัสโครงสร้างเคมีและคุณลักษณะโมเลกุล

### 2.2.1 SMILES

SMILES (Simplified Molecular Input Line Entry System) เป็นระบบแทนโครงสร้างทางเคมีด้วยสายอักขระ ทำให้สามารถจัดเก็บและประมวลผลโครงสร้างโมเลกุลด้วยคอมพิวเตอร์ได้อย่างมีประสิทธิภาพ โมเลกุลเดียวกันอาจเขียนเป็น SMILES ได้หลายรูปแบบ จึงจำเป็นต้องแปลงให้อยู่ในรูปมาตรฐาน (Canonical SMILES) ก่อนการเปรียบเทียบหรือยุบข้อมูลซ้ำ

### 2.2.2 Morgan Fingerprints (ECFP4)

Morgan Fingerprints เป็นอัลกอริทึมเข้ารหัสโครงสร้าง 2 มิติที่พัฒนาโดย Rogers และ Hahn (2010) หลักการทำงานคือการพิจารณาสภาพแวดล้อมรอบอะตอมแต่ละตัวภายในรัศมีที่กำหนด แล้วแปลงเป็นเวกเตอร์บิตความยาวคงที่

เมื่อกำหนดรัศมี r = 2 อัลกอริทึมจะพิจารณาอะตอมข้างเคียงที่อยู่ห่างออกไปไม่เกิน 2 พันธะ ซึ่งเทียบเท่ากับเส้นผ่านศูนย์กลาง 4 พันธะ จึงเรียกว่า ECFP4 (Extended-Connectivity Fingerprint, diameter 4) ผลลัพธ์คือเวกเตอร์บิตขนาด 1,024 บิต โดยแต่ละบิตมีค่าเป็น 0 หรือ 1 บ่งบอกการมีอยู่หรือไม่มีของโครงสร้างย่อยแบบใดแบบหนึ่ง

ข้อได้เปรียบสำคัญของ Morgan Fingerprints คือความสามารถในการจับคู่ย้อนกลับ (Bit Mapping) กล่าวคือ เมื่อทราบว่าบิตใดมีความสำคัญ สามารถย้อนกลับไปวาดภาพโครงสร้างย่อยที่บิตนั้นเป็นตัวแทนได้ ทำให้ผลการวิเคราะห์สามารถตีความเชิงเคมีได้

**ข้อจำกัด** Morgan Fingerprints ในการตั้งค่าปกติไม่บันทึกข้อมูลสเตอริโอเคมี (Stereochemistry) ทำให้สเตอริโอไอโซเมอร์ที่มีโครงสร้างเชิงเส้นเหมือนกันแต่มีการจัดเรียงในสามมิติต่างกันได้เวกเตอร์บิตที่เหมือนกันทุกประการ

### 2.2.3 กฎของลิพินสกีและ Lipinski Descriptors

Lipinski และคณะ (2001) เสนอกฎห้าประการ (Rule of Five) สำหรับประเมินความเป็นไปได้ที่สารจะพัฒนาเป็นยารับประทาน โดยสารที่มีคุณสมบัติเป็นยาที่ดีมักมีลักษณะดังนี้

| Descriptor | เกณฑ์ | ความหมาย |
|---|---|---|
| MW (Molecular Weight) | ≤ 500 Da | น้ำหนักโมเลกุล |
| LogP | ≤ 5 | ค่าสัมประสิทธิ์การแบ่งน้ำ-ออกทานอล บ่งบอกความชอบไขมัน |
| HBD (H-Bond Donors) | ≤ 5 | จำนวนอะตอมผู้ให้พันธะไฮโดรเจน |
| HBA (H-Bond Acceptors) | ≤ 10 | จำนวนอะตอมผู้รับพันธะไฮโดรเจน |

คุณลักษณะเหล่านี้เป็นค่าตัวเลขต่อเนื่องที่มีสเกลแตกต่างกันมาก (เช่น MW อยู่ในหลักร้อย ขณะที่ HBD อยู่ในหลักหน่วย) จึงจำเป็นต้องปรับมาตรฐานก่อนใช้กับแบบจำลองที่ไวต่อสเกล เช่น SVR

### 2.2.4 คุณลักษณะแบบผสม (Hybrid Features)

การรวม Morgan Fingerprints ซึ่งเป็นข้อมูลไบนารีเชิงโครงสร้าง เข้ากับ Lipinski Descriptors ซึ่งเป็นข้อมูลตัวเลขต่อเนื่องเชิงคุณสมบัติ ทำให้ได้ชุดคุณลักษณะที่ครอบคลุมทั้งมิติโครงสร้างเฉพาะและมิติคุณสมบัติภาพรวมของโมเลกุล รวมเป็น 1,024 + 4 = 1,028 คุณลักษณะ

ความท้าทายของการรวมข้อมูลสองประเภทนี้คือ ข้อมูลไบนารีไม่ควรถูกปรับมาตรฐาน (เพราะมีค่า 0/1 อยู่แล้ว) ขณะที่ข้อมูลตัวเลขต่อเนื่องจำเป็นต้องปรับ จึงต้องใช้กลไก `ColumnTransformer` เพื่อจัดการคอลัมน์แต่ละกลุ่มแยกจากกัน

## 2.3 อัลกอริทึมการเรียนรู้ของเครื่อง

### 2.3.1 Dummy Regressor

แบบจำลองพื้นฐานที่ทำนายผลลัพธ์เป็นค่าเฉลี่ยของชุดข้อมูลฝึกเสมอ โดยไม่พิจารณาคุณลักษณะใด ๆ ใช้เป็นเกณฑ์มาตรฐานเปรียบเทียบขั้นต่ำ (Baseline Benchmark) หากแบบจำลองที่ซับซ้อนกว่าไม่สามารถทำได้ดีกว่า Dummy Regressor แสดงว่าคุณลักษณะที่ใช้ไม่มีสารสนเทศเพียงพอ หรือกระบวนการสร้างแบบจำลองมีข้อผิดพลาด

ในทางทฤษฎี Dummy Regressor จะให้ค่า R² ประมาณ 0 บนชุดทดสอบ และอาจติดลบเล็กน้อยหากค่าเฉลี่ยของชุดฝึกต่างจากชุดทดสอบ

### 2.3.2 Random Forest Regressor

Random Forest เป็นแบบจำลองรวมกลุ่ม (Ensemble Learning) ชนิด Bagging ที่พัฒนาโดย Breiman (2001) หลักการคือการสร้างต้นไม้ตัดสินใจจำนวนมากจากตัวอย่างที่สุ่มเลือกแบบมีการแทนที่ (Bootstrap Sampling) และในแต่ละโหนดจะพิจารณาเพียงคุณลักษณะย่อยที่สุ่มเลือกมา แล้วนำผลทำนายของทุกต้นมาเฉลี่ยกัน

การรวมผลจากต้นไม้หลายต้นช่วยลดความแปรปรวน (Variance) และลดปัญหาการเรียนรู้เกิน (Overfitting) ได้อย่างมีประสิทธิภาพ นอกจากนี้ค่าเบี่ยงเบนมาตรฐานของการทำนายจากต้นไม้แต่ละต้นยังสามารถใช้เป็นตัวแทนความไม่แน่นอนของการทำนายได้

### 2.3.3 XGBoost Regressor

XGBoost (Extreme Gradient Boosting) พัฒนาโดย Chen และ Guestrin (2016) เป็นอัลกอริทึม Boosting ที่สร้างต้นไม้แบบต่อเนื่อง โดยต้นไม้แต่ละต้นจะเรียนรู้เพื่อแก้ไขความคลาดเคลื่อนตกค้าง (Residuals) ของต้นไม้ก่อนหน้า ผ่านการปรับลดด้วยวิธี Gradient Descent

XGBoost มีกลไกการปรับให้เป็นปกติ (Regularization) ทั้งแบบ L1 และ L2 ในฟังก์ชันวัตถุประสงค์ ทำให้ควบคุมความซับซ้อนของแบบจำลองได้ดี และมีการปรับแต่งเชิงวิศวกรรมที่ทำให้ประมวลผลได้รวดเร็ว จึงเป็นที่นิยมอย่างสูงในงานข้อมูลตาราง

### 2.3.4 Support Vector Regressor (SVR)

SVR เป็นอัลกอริทึมที่หาไฮเปอร์เพลนที่เหมาะสมที่สุดภายในขอบเขตความคลาดเคลื่อน ε (Epsilon-insensitive tube) โดยจุดข้อมูลที่อยู่ภายในขอบเขตนี้จะไม่ถูกนับเป็นความคลาดเคลื่อน การใช้ฟังก์ชันเคอร์เนลแบบ RBF (Radial Basis Function) ทำให้ SVR สามารถจับความสัมพันธ์ที่ไม่เป็นเชิงเส้นได้

SVR มีความไวต่อสเกลของข้อมูลอย่างมาก เนื่องจากการคำนวณระยะทางในฟังก์ชันเคอร์เนล จึงจำเป็นต้องปรับมาตรฐานคุณลักษณะเชิงตัวเลขก่อนใช้งาน

## 2.4 การป้องกันการรั่วไหลของข้อมูล

### 2.4.1 นิยามและประเภทของ Data Leakage

Data Leakage คือการที่สารสนเทศจากชุดข้อมูลทดสอบรั่วไหลเข้าสู่กระบวนการฝึกแบบจำลอง ทำให้ผลการประเมินสูงเกินความเป็นจริง ในบริบทของงาน QSAR มี Data Leakage ที่พบบ่อยสองรูปแบบ

**รูปแบบที่ 1: Preprocessing Leakage** เกิดจากการคำนวณค่าสถิติสำหรับการปรับมาตรฐาน (เช่น ค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐาน) จากข้อมูลทั้งชุดก่อนแบ่ง Train/Test ทำให้ค่าสถิติของชุดทดสอบมีอิทธิพลต่อการแปลงข้อมูลฝึก

**รูปแบบที่ 2: Feature Selection Leakage** เกิดจากการคัดเลือกคุณลักษณะโดยพิจารณาความสัมพันธ์กับตัวแปรตามบนข้อมูลทั้งชุด ก่อนแบ่งข้อมูล ทำให้คุณลักษณะที่ถูกเลือกมี "ความรู้" เกี่ยวกับชุดทดสอบติดมาด้วย รูปแบบนี้มักส่งผลรุนแรงกว่ารูปแบบแรก โดยเฉพาะเมื่อจำนวนคุณลักษณะตั้งต้นมีมาก

### 2.4.2 การแก้ปัญหาด้วย Pipeline และ ColumnTransformer

Scikit-learn Pipeline เป็นกลไกที่ผนวกขั้นตอนการแปลงข้อมูลเข้ากับแบบจำลองให้เป็นวัตถุเดียว เมื่อเรียกใช้กับกระบวนการ Cross-Validation ระบบจะเรียก `fit()` ของทุกขั้นตอนใหม่ในแต่ละ Fold โดยใช้เฉพาะข้อมูลชุดฝึกของ Fold นั้น จึงรับประกันได้ว่าค่าสถิติที่ใช้แปลงข้อมูลไม่ได้มาจากชุดตรวจสอบ

`ColumnTransformer` ทำหน้าที่กำหนดว่าคอลัมน์กลุ่มใดจะผ่านการแปลงแบบใด ในโครงงานนี้กำหนดให้คอลัมน์ Fingerprint จำนวน 1,024 คอลัมน์ผ่านแบบ `passthrough` (ไม่แปลง) และคอลัมน์ Lipinski จำนวน 4 คอลัมน์ผ่าน `StandardScaler`

## 2.5 การประเมินประสิทธิภาพแบบจำลอง

### 2.5.1 ตัวชี้วัด

| ตัวชี้วัด | สูตร | การตีความ |
|---|---|---|
| R² | $1 - \frac{SS_{res}}{SS_{tot}}$ | สัดส่วนความแปรปรวนที่แบบจำลองอธิบายได้ ค่าสูงสุด 1.0 ค่าติดลบหมายถึงแย่กว่าการทำนายด้วยค่าเฉลี่ย |
| RMSE | $\sqrt{\frac{1}{n}\sum(y_i - \hat{y}_i)^2}$ | รากที่สองของค่าเฉลี่ยความคลาดเคลื่อนกำลังสอง ให้น้ำหนักกับความคลาดเคลื่อนขนาดใหญ่ |
| MAE | $\frac{1}{n}\sum\|y_i - \hat{y}_i\|$ | ค่าเฉลี่ยความคลาดเคลื่อนสัมบูรณ์ ทนต่อค่าผิดปกติมากกว่า RMSE |
| Spearman ρ | สหสัมพันธ์อันดับ | ความสามารถในการจัดอันดับสาร ซึ่งสำคัญกว่าค่าสัมบูรณ์ในงานคัดกรองยา |

ในบริบท QSAR ค่า RMSE และ MAE มีหน่วยเป็น log unit ค่า RMSE = 0.5 หมายความว่าโดยเฉลี่ยแบบจำลองทำนายคลาดเคลื่อนประมาณ 3 เท่าของค่า IC50 จริง

### 2.5.2 K-Fold Cross-Validation

การแบ่งชุดข้อมูลฝึกออกเป็น K ส่วนเท่า ๆ กัน แล้วฝึกแบบจำลอง K ครั้ง โดยแต่ละครั้งใช้ K−1 ส่วนเป็นข้อมูลฝึกและ 1 ส่วนเป็นข้อมูลตรวจสอบ ผลลัพธ์ที่ได้จึงมีความน่าเชื่อถือมากกว่าการแบ่งครั้งเดียว และค่าส่วนเบี่ยงเบนมาตรฐานข้าม Fold ยังบ่งบอกความเสถียรของแบบจำลอง

ส่วนต่างระหว่าง R² ของชุดฝึกกับชุดตรวจสอบ (Train−CV Gap) เป็นดัชนีบ่งชี้การเรียนรู้เกิน ค่ายิ่งสูงแสดงว่าแบบจำลองจดจำข้อมูลฝึกมากเกินไป

### 2.5.3 Scaffold Split

Bemis และ Murcko (1996) เสนอแนวคิดการสกัดโครงสร้างแกนกลางของโมเลกุล (Molecular Framework) โดยตัดหมู่แทนที่ด้านข้างออก เหลือเฉพาะระบบวงแหวนและสายเชื่อม

Sheridan (2013) ชี้ว่าการแบ่งข้อมูลแบบสุ่มในงาน QSAR ทำให้สารในอนุกรมเคมีเดียวกัน (Analog Series) กระจายอยู่ทั้งชุดฝึกและชุดทดสอบ ส่งผลให้ค่า R² สูงเกินจริง เพราะแบบจำลองเพียงต้องจดจำอนุกรมนั้นแทนที่จะเรียนรู้ความสัมพันธ์เชิงโครงสร้างที่แท้จริง การแบ่งข้อมูลโดยจัดโมเลกุลที่มี Scaffold เดียวกันไว้ฝั่งเดียวกันจึงสะท้อนสถานการณ์การทำนายสารใหม่ได้ตรงกว่า

### 2.5.4 Applicability Domain

Applicability Domain คือขอบเขตของปริภูมิเคมีที่แบบจำลองมีความน่าเชื่อถือ วิธีประเมินที่นิยมคือการคำนวณความคล้ายคลึงแบบ Tanimoto ระหว่างสารที่ต้องการทำนายกับสารที่ใกล้ที่สุดในชุดข้อมูลฝึก

$$T(A,B) = \frac{|A \cap B|}{|A \cup B|}$$

โดยทั่วไปหากค่าความคล้ายคลึงสูงสุดต่ำกว่า 0.4 ถือว่าสารนั้นอยู่นอกขอบเขตการใช้งาน และผลทำนายไม่ควรนำไปใช้เป็นค่าสัมบูรณ์

## 2.6 การอธิบายแบบจำลองด้วย SHAP

SHAP (SHapley Additive exPlanations) พัฒนาโดย Lundberg และ Lee (2017) เป็นวิธีอธิบายการตัดสินใจของแบบจำลองบนพื้นฐานทฤษฎีเกมสหกรณ์ โดยคำนวณค่า Shapley ซึ่งเป็นการกระจายผลตอบแทนให้ผู้เล่นแต่ละคนอย่างยุติธรรมตามการมีส่วนร่วม

ในบริบทของการเรียนรู้ของเครื่อง "ผู้เล่น" คือคุณลักษณะแต่ละตัว และ "ผลตอบแทน" คือค่าที่แบบจำลองทำนาย ค่า SHAP ของคุณลักษณะ j ในตัวอย่าง i เขียนแทนด้วย φ_j^(i) ซึ่งบอกว่าคุณลักษณะนั้นผลักดันการทำนายให้สูงขึ้นหรือต่ำลงเท่าใดเมื่อเทียบกับค่าฐาน

ความสำคัญโดยรวมของคุณลักษณะคำนวณจากค่าเฉลี่ยสัมบูรณ์

$$\text{Importance}_j = \frac{1}{N}\sum_{i=1}^{N}|\phi_j^{(i)}|$$

สำหรับแบบจำลองประเภทต้นไม้ สามารถใช้ `TreeExplainer` ซึ่งคำนวณค่า SHAP ได้อย่างแม่นยำในเวลาพหุนาม แทนที่จะต้องประมาณค่า

Rodríguez-Pérez และ Bajorath (2020) ได้ประยุกต์ใช้ค่า Shapley ในการตีความการทำนายฤทธิ์ของสารประกอบ และแสดงให้เห็นว่าวิธีนี้สามารถเชื่อมโยงผลการทำนายกลับไปยังโครงสร้างย่อยที่ตีความเชิงเคมีได้

## 2.7 งานวิจัยที่เกี่ยวข้อง

Nantasenamat และคณะ (2010) ได้สรุปภาพรวมเชิงปฏิบัติของงาน QSAR โดยเน้นความสำคัญของการเตรียมข้อมูล การเลือกคุณลักษณะ และการตรวจสอบความถูกต้องของแบบจำลอง งานนี้เป็นกรอบแนวคิดพื้นฐานที่โครงงานปัจจุบันยึดถือ

Gaulton และคณะ (2017) ได้อธิบายโครงสร้างและการใช้งานฐานข้อมูล ChEMBL ซึ่งเป็นฐานข้อมูลสารออกฤทธิ์ทางชีวภาพที่ผ่านการดูแลด้วยมือ (Manually Curated) ครอบคลุมข้อมูลจากวรรณกรรมเคมียาและสิทธิบัตร ประเด็นสำคัญที่งานนี้ชี้ไว้คือ ข้อมูลใน ChEMBL มาจากหลายห้องปฏิบัติการที่ใช้โปรโตคอลต่างกัน จึงมีความแปรปรวนภายในสูง จำเป็นต้องกรองและยุบข้อมูลซ้ำอย่างระมัดระวัง

Maggiora (2006) ได้อธิบายปรากฏการณ์ Activity Cliff ซึ่งเป็นกรณีที่โมเลกุลมีโครงสร้างคล้ายกันมากแต่มีฤทธิ์แตกต่างกันอย่างมาก ปรากฏการณ์นี้เป็นข้อจำกัดเชิงหลักการของแบบจำลอง QSAR ที่ตั้งอยู่บนสมมติฐานว่าโครงสร้างที่คล้ายกันควรมีฤทธิ์ใกล้เคียงกัน

**ช่องว่างที่โครงงานนี้เติมเต็ม** งานวิจัย QSAR จำนวนมากรายงานเฉพาะผลการแบ่งข้อมูลแบบสุ่มและไม่ได้ประเมินขอบเขตการใช้งานของแบบจำลอง โครงงานนี้จึงรายงานผลทั้งการแบ่งแบบสุ่มและแบบ Scaffold ควบคู่กัน พร้อมทดสอบข้ามชุดข้อมูลกับสารจากแหล่งอิสระ และวิเคราะห์ Applicability Domain เชิงปริมาณ เพื่อให้ได้ภาพความสามารถทำนายที่ตรงกับความเป็นจริงในทางปฏิบัติ


## 3.7 การสำรวจข้อมูล (Phase 4)

ดำเนินการสำรวจข้อมูลเชิงพรรณนา ประกอบด้วยการวิเคราะห์การแจกแจงของ pIC50 การเปรียบเทียบปริภูมิเคมีบนแกน MW–LogP การทดสอบความแตกต่างของ Lipinski Descriptors ระหว่างกลุ่มฤทธิ์ด้วยสถิติ Mann-Whitney U การสกัดโครงสร้างแกนกลาง Murcko และการเปรียบเทียบปริภูมิเคมีของชุดข้อมูลทั้งสามชั้น

## 3.8 การแบ่งข้อมูล (Phase 5)

### 3.8.1 Random Split

แบ่งข้อมูลเป็นชุดฝึกร้อยละ 75 และชุดทดสอบร้อยละ 25 ด้วย `train_test_split` โดยกำหนด `stratify` ตามคอลัมน์กลุ่มฤทธิ์ เพื่อให้สัดส่วน active/intermediate/inactive เท่ากันทั้งสองฝั่ง

### 3.8.2 Scaffold Split

สกัดโครงสร้างแกนกลาง Bemis–Murcko ของทุกโมเลกุล จัดกลุ่มตาม Scaffold แล้วเรียงลำดับกลุ่มจากใหญ่ไปเล็ก จากนั้นทยอยจัดกลุ่มใหญ่เข้าชุดฝึกก่อนจนเต็มโควตา ส่วนที่เหลือเข้าชุดทดสอบ วิธีนี้ทำให้ชุดทดสอบประกอบด้วยโครงสร้างแกนกลางที่พบไม่บ่อยและไม่ปรากฏในชุดฝึกเลย

## 3.9 การสร้าง Pipeline ป้องกันการรั่วไหล

โครงสร้าง Pipeline ประกอบด้วยสองขั้นตอนหลัก

```python
preprocessor = ColumnTransformer([
    ('fp',   'passthrough',    FP_COLS),     # 1,024 บิต ไม่ปรับสเกล
    ('desc', StandardScaler(), DESC_COLS),   # 4 ตัว ปรับมาตรฐาน
], remainder='drop')

pipe = Pipeline([
    ('prep',  preprocessor),
    ('model', estimator),
])
```

เมื่อส่ง Pipeline นี้เข้าสู่ `cross_validate` ระบบจะเรียก `pipe.fit()` ใหม่ในทุก Fold โดยใช้เฉพาะข้อมูลชุดฝึกของ Fold นั้น ทำให้ค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐานที่ `StandardScaler` ใช้ไม่ได้รับอิทธิพลจากชุดตรวจสอบ

| E5b | B ผิด — SelectKBest บนข้อมูลทั้งชุด | 0.6008 | **+0.0116** |

ผลการทดลองนี้เป็นข้อค้นพบที่ต้องรายงานอย่างตรงไปตรงมา เนื่องจากไม่เป็นไปตามที่คาดการณ์ไว้ล่วงหน้า

**การทดลอง E5 แสดงว่า Preprocessing Leakage แทบไม่มีผลเลย** ส่วนต่างเพียง +0.0001 R² อธิบายได้จากสองเหตุผล ประการแรก มีเพียง 4 คุณลักษณะจากทั้งหมด 1,028 คุณลักษณะที่ผ่านการปรับสเกล คิดเป็นร้อยละ 0.39 เท่านั้น ประการที่สอง ขนาดชุดฝึก 1,648 ตัวอย่างมีขนาดใหญ่เพียงพอที่ค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐานที่คำนวณจากชุดฝึกของแต่ละ Fold แทบไม่ต่างจากที่คำนวณจากข้อมูลทั้งชุด

ในทางปฏิบัติ **ตัวเลขที่ควรอ้างอิงเมื่อพูดถึงการทำนายสารที่มีโครงสร้างแกนกลางใหม่คือ R² = 0.5127** ไม่ใช่ 0.7034

## 4.6 การวิเคราะห์ค่าคลาดเคลื่อน

ผลการวิเคราะห์นี้เปิดเผยจุดอ่อนสำคัญของแบบจำลอง กล่าวคือ **แบบจำลองทำนายสารกลุ่ม inactive สูงเกินจริงอย่างเป็นระบบเฉลี่ย 0.72 log unit** และมีค่า RMSE สูงถึง 0.9667 เกือบสองเท่าของอีกสองกลุ่ม

สาเหตุมาจากความไม่สมดุลของชุดข้อมูลฝึก ซึ่งมีสาร active ถึง 1,453 ตัว แต่มี inactive เพียง 198 ตัว คิดเป็นอัตราส่วน 7.3 ต่อ 1 แบบจำลองจึงมีแนวโน้มเอนเอียงไปทางการทำนายค่าสูง

ค่าคลาดเคลื่อนที่มากที่สุดสามอันดับแรกล้วนเป็นสารกลุ่ม inactive ที่ถูกทำนายเป็น active ได้แก่ ค่าจริง 4.190 ทำนาย 7.087 (คลาดเคลื่อน −2.897), ค่าจริง 4.064 ทำนาย 6.508 (คลาดเคลื่อน −2.444) และค่าจริง 4.458 ทำนาย 6.690 (คลาดเคลื่อน −2.232)

**ผลนี้เป็นผลลบที่ต้องรายงานอย่างตรงไปตรงมา** ค่า R² ที่ติดลบหมายความว่าแบบจำลองทำนายชุด DDH ได้แย่กว่าการทายด้วยค่าเฉลี่ยของชุด DDH เอง และค่า Bias ที่ +1.1855 แสดงว่าแบบจำลองทำนายสูงเกินจริงอย่างเป็นระบบถึง 1.19 log unit หรือคิดเป็นการประเมินความแรงเกินจริงประมาณ 15 เท่า

| ชุดข้อมูล | จำนวน | Tanimoto สูงสุดเฉลี่ย | มัธยฐาน | ร้อยละที่ต่ำกว่า 0.4 |
|---|---|---|---|---|

การวิเคราะห์ Applicability Domain อธิบายความล้มเหลวข้างต้นได้อย่างชัดเจน สารในชุด DDH ถึงร้อยละ 84.4 มีค่าความคล้ายคลึง Tanimoto สูงสุดต่อชุดฝึกต่ำกว่าเกณฑ์ 0.4 โดยมีค่ามัธยฐานเพียง 0.2897 ขณะที่ชุดทดสอบภายในมีเพียงร้อยละ 7.6 ที่อยู่นอกเกณฑ์ และมีค่ามัธยฐานสูงถึง 0.7972

กล่าวอีกนัยหนึ่ง ชุด DDH แทบเป็นสารคนละปริภูมิเคมีกับข้อมูลที่ใช้ฝึก โดยมีระดับความแตกต่างใกล้เคียงกับชุด MultiTarget ซึ่งเป็นสารที่ออกฤทธิ์ต่อเป้าหมายคนละชนิดโดยสิ้นเชิง (DRD2, HDAC1, BACE1)

นอกจากนี้ยังมีปัจจัยเสริมคือการเลื่อนของการกระจายตัวแปรตาม (Label Distribution Shift) โดยชุด ChEMBL มี pIC50 เฉลี่ย 6.393 และประกอบด้วยสาร active เป็นส่วนใหญ่ ขณะที่ชุด DDH มีค่าเฉลี่ยเพียง 4.872 และเป็นสาร inactive ถึง 61 จาก 90 ตัว เมื่อประกอบกับจุดอ่อนของแบบจำลองที่ทำนายสาร inactive สูงเกินจริงตามที่พบในหัวข้อ 4.6 จึงส่งผลให้ความคลาดเคลื่อนสะสมรุนแรงขึ้น

# บทที่ 5 สรุปผล อภิปรายผล และข้อเสนอแนะ

## 5.1 สรุปผลการดำเนินงาน

โครงงานนี้ได้พัฒนาแบบจำลองการเรียนรู้ของเครื่องสำหรับทำนายค่าฤทธิ์การยับยั้งเอนไซม์ SARS-CoV-2 Main Protease ในรูป pIC50 แบบ In Silico โดยดำเนินงานครบทั้ง 9 ระยะตามแผน สรุปผลได้ดังนี้

**ด้านข้อมูล** รวบรวมข้อมูลจาก ChEMBL เป้าหมาย `CHEMBL4523582` จำนวน 4,867 รายการ กรอง assay เฉพาะที่วัด 3CL-Pro เหลือ 2,889 รายการ (คัดออกร้อยละ 40.6 ซึ่งเป็น assay ของ nsp3, PLpro และ papain-like protease) ผ่านการทำความสะอาด 13 ขั้นตอน ได้ชุดข้อมูลมาตรฐาน **2,198 โมเลกุลที่ไม่ซ้ำกัน** ประกอบด้วยสาร active 1,453 ตัว intermediate 547 ตัว และ inactive 198 ตัว มีความหลากหลายเชิงโครงสร้างสูงโดยมี Murcko Scaffold ไม่ซ้ำ 976 แบบ

**ด้านแบบจำลอง** XGBoost ให้ประสิทธิภาพสูงสุดบนชุดทดสอบ โดยได้ **R² = 0.7034, RMSE = 0.5487, MAE = 0.3918 และ Spearman ρ = 0.8415** ซึ่งเหนือกว่าแบบจำลองพื้นฐานอย่างชัดเจน (R² = −0.0000) การทำนายร้อยละ 93.6 มีความคลาดเคลื่อนไม่เกิน 1 log unit เมื่อประเมินด้วยการแบ่งข้อมูลตามโครงสร้างแกนกลาง ค่า R² ลดลงเหลือ 0.5127

**ด้านการวิเคราะห์ SAR** ระบุคุณลักษณะสำคัญได้ โดยน้ำหนักโมเลกุลมีอิทธิพลสูงสุด (Mean|SHAP| = 0.1165) และสามารถจับคู่ย้อนกลับเป็นภาพโครงสร้างย่อย 2 มิติได้ 6 บิต ซึ่งมีการกระจายตัวระหว่างกลุ่ม active และ inactive ที่แตกต่างกันอย่างชัดเจน

### 5.2.1 อภิปรายวัตถุประสงค์ที่ 1

แบบจำลองที่พัฒนาขึ้นบรรลุเกณฑ์ "ดี" ที่กำหนดไว้ล่วงหน้า (R² ในช่วง 0.60–0.75) ค่า RMSE = 0.5487 log unit หมายความว่าโดยเฉลี่ยแบบจำลองทำนายค่า IC50 คลาดเคลื่อนประมาณ 3.5 เท่า ซึ่งอยู่ในระดับที่ยอมรับได้สำหรับงานคัดกรองเบื้องต้น เนื่องจากความแปรปรวนของการทดลองในห้องปฏิบัติการเองระหว่างห้องปฏิบัติการต่างกันก็อยู่ในระดับใกล้เคียงกัน

ค่า Spearman ρ = 0.8415 ซึ่งสูงกว่าที่ค่า R² บ่งชี้ เป็นข้อค้นพบที่มีนัยสำคัญเชิงปฏิบัติ เพราะในงานคัดกรองยาสิ่งที่ต้องการมากที่สุดคือความสามารถ **จัดลำดับ** สารเพื่อเลือกไปทดสอบจริง ไม่ใช่ความแม่นยำของค่าสัมบูรณ์

ประเด็นที่น่าสังเกตคือ XGBoost ทำได้ต่ำที่สุดในระยะ Cross-Validation ก่อนปรับจูน (CV R² = 0.5803) แต่กลับดีที่สุดหลังปรับจูน (Test R² = 0.7034) แสดงว่าค่าเริ่มต้นของ XGBoost ไม่เหมาะกับข้อมูลชุดนี้ และการปรับจูนไฮเปอร์พารามิเตอร์มีความสำคัญมากกว่าการเลือกอัลกอริทึม

### 5.2.2 อภิปรายวัตถุประสงค์ที่ 2

การสร้าง Pipeline ที่ป้องกัน Data Leakage บรรลุผลตามวัตถุประสงค์ในเชิงระเบียบวิธี แต่**ผลการวัดเชิงปริมาณไม่เป็นไปตามสมมติฐานตั้งต้น**

สมมติฐานเดิมคาดว่าการปรับสเกลก่อนแบ่งข้อมูลจะทำให้ผลสูงเกินจริงอย่างเห็นได้ชัด แต่ผลการทดลอง E5 พบส่วนต่างเพียง +0.0001 R² คำอธิบายคือสัดส่วนคุณลักษณะที่ต้องปรับสเกลมีเพียงร้อยละ 0.39 และขนาดชุดข้อมูลใหญ่เพียงพอ

อย่างไรก็ตาม เมื่อออกแบบการทดลองเพิ่มเติม E5b เพื่อตรวจสอบ Feature Selection Leakage ซึ่งเป็นรูปแบบที่ตรวจพบจริงในไฟล์ `xfinal.csv` ที่ได้รับมอบมา พบอคติบวก +0.0116 R² ซึ่งมากกว่ารูปแบบแรกถึง 116 เท่า

**บทเรียนเชิงระเบียบวิธี** การใช้ Pipeline ยังคงเป็นแนวปฏิบัติที่ถูกต้องและควรทำเสมอ แต่ผู้วิจัยควรตระหนักว่าความรุนแรงของ Data Leakage ขึ้นอยู่กับ **สัดส่วนของคุณลักษณะที่ได้รับผลกระทบ** และ **ขนาดของชุดข้อมูล** การรั่วไหลจากการคัดเลือกคุณลักษณะเป็นภัยคุกคามที่ใหญ่กว่าการรั่วไหลจากการปรับสเกลอย่างมีนัยสำคัญ

สำหรับผลการศึกษา Ablation พบว่า Hybrid Features ให้ผลดีที่สุดจริง แต่ส่วนเพิ่มจาก Lipinski Descriptors มีเพียง +0.0112 R² ขณะที่การวิเคราะห์ SHAP กลับพบว่า Lipinski ติดอันดับ 20 แรกครบทั้ง 4 ตัว และ MW เป็นอันดับ 1 ผลสองอย่างนี้ไม่ขัดแย้งกัน แต่สะท้อนปรากฏการณ์ **คุณลักษณะสำคัญแต่ซ้ำซ้อน** เพราะ Morgan Fingerprints เข้ารหัสข้อมูลขนาดโมเลกุลไว้โดยอ้อมอยู่แล้ว

### 5.2.3 อภิปรายวัตถุประสงค์ที่ 3

การวิเคราะห์ SAR ให้ผลที่ตีความเชิงเคมีได้อย่างสอดคล้อง โดยเฉพาะบิต FP_10 ที่มีอัตราส่วนความเข้มข้นระหว่างกลุ่ม active ต่อ inactive สูงถึง 9.3 เท่า และโมเลกุลตัวอย่างมีหมู่แอลดีไฮด์ซึ่งเป็นหมู่ที่ทราบกันว่าสร้างพันธะกับซิสเตอีนในช่องเร่งปฏิกิริยาของ M^pro ได้

อย่างไรก็ตาม ต้องย้ำข้อจำกัดที่ประกาศไว้ตั้งแต่ต้นว่า ผลการวิเคราะห์ SHAP แสดง **ความสัมพันธ์เชิงสถิติ** ระหว่างชิ้นส่วนโมเลกุลกับค่าที่แบบจำลองทำนาย ไม่สามารถอ้างเป็น **กลไกการจับทางชีวภาพเชิงสาเหตุ** ในระดับ 3 มิติได้ ความสอดคล้องกับความรู้ทางเคมียาที่พบเป็นเพียงหลักฐานสนับสนุนความสมเหตุสมผล ไม่ใช่การพิสูจน์กลไก การยืนยันที่แท้จริงต้องอาศัย Molecular Docking, Molecular Dynamics และการทดสอบ In Vitro

กรณีบิต FP_807 เป็นตัวอย่างที่ดีของความจำเป็นในการตรวจสอบผล SHAP ด้วยสถิติเชิงพรรณนาประกอบ เนื่องจากบิตนี้ปรากฏในโมเลกุลถึงร้อยละ 86.6 ทั้งในกลุ่ม active และ inactive ค่า SHAP ที่ติดลบจึงไม่มีความหมายเชิงเคมีที่ตีความได้ หากรายงานเฉพาะอันดับ Mean|SHAP| โดยไม่ดูสัดส่วนการปรากฏ อาจนำไปสู่การตีความที่ผิดพลาด

## 5.3 ข้อค้นพบสำคัญที่นอกเหนือจากวัตถุประสงค์

### 5.3.1 ความล้มเหลวของการทดสอบข้ามชุดข้อมูล

ข้อค้นพบที่มีคุณค่าที่สุดของโครงงานนี้อาจเป็นผลลบ กล่าวคือ แบบจำลองที่ได้ค่า R² = 0.7034 บนชุดทดสอบภายใน กลับได้ **R² = −1.72** เมื่อทดสอบกับสาร COVID-19 จากแหล่งอิสระ 90 ตัว

การวิเคราะห์ Applicability Domain อธิบายสาเหตุได้อย่างชัดเจนว่า ร้อยละ 84.4 ของสารในชุดทดสอบข้ามแหล่งมีค่าความคล้ายคลึง Tanimoto ต่อชุดฝึกต่ำกว่า 0.4 ซึ่งใกล้เคียงกับชุดสารที่ออกฤทธิ์ต่อเป้าหมายคนละชนิดโดยสิ้นเชิง

**นัยเชิงวิชาการ** ผลนี้เป็นหลักฐานเชิงประจักษ์ที่สนับสนุนข้อวิจารณ์ที่มีต่องานวิจัย QSAR จำนวนมากที่รายงานเฉพาะค่า R² บนชุดทดสอบภายใน โดยไม่ประเมิน Applicability Domain หรือทดสอบข้ามแหล่งข้อมูล ค่า R² ที่สูงในการแบ่งข้อมูลแบบสุ่มไม่ได้รับประกันความสามารถทำนายในทางปฏิบัติเลย

### 5.3.2 ผลกระทบของความไม่สมดุลของข้อมูล

การวิเคราะห์ค่าคลาดเคลื่อนแยกตามกลุ่มฤทธิ์เผยให้เห็นว่า แบบจำลองทำนายสาร inactive สูงเกินจริงอย่างเป็นระบบเฉลี่ย 0.72 log unit ซึ่งเป็นผลจากอัตราส่วนสาร active ต่อ inactive ในชุดฝึกที่ 7.3 ต่อ 1

ข้อค้นพบนี้เชื่อมโยงโดยตรงกับความล้มเหลวในหัวข้อ 5.3.1 เพราะชุด DDH ประกอบด้วยสาร inactive ถึง 61 จาก 90 ตัว จึงตกอยู่ในสถานการณ์ที่แบบจำลองอ่อนแอที่สุดพอดี ความไม่สมดุลของข้อมูลจึงไม่ได้ส่งผลเฉพาะในงานจำแนกประเภทเท่านั้น แต่ส่งผลต่องานถดถอยด้วยเมื่อการกระจายของตัวแปรตามไม่สมมาตร

### 5.3.3 ข้อจำกัดของ Morgan Fingerprints กับสเตอริโอเคมี

การวิเคราะห์ Activity Cliff พบคู่โมเลกุลที่มีความคล้ายคลึงเกิน 0.85 จำนวน 635 คู่ ในจำนวนนี้มี 23 คู่ (ร้อยละ 3.62) ที่มีค่า pIC50 ต่างกันเกิน 1.5 log unit

เมื่อตรวจสอบคู่ที่รุนแรงที่สุดพบว่าเป็น **สเตอริโอไอโซเมอร์** ตัวอย่างเช่น สาร CHEMBL5412571 มี pIC50 = 8.52 ขณะที่ CHEMBL5197241 มี pIC50 = 6.33 ทั้งสองมีสูตรโครงสร้างเชิงเส้นเหมือนกันทุกประการ ต่างกันเพียงการจัดเรียงสเตอริโอที่ศูนย์กลางไครัลสองตำแหน่ง แต่มีฤทธิ์ต่างกันถึง 2.19 log unit หรือประมาณ 155 เท่า

ค่าความคล้ายคลึง Tanimoto ระหว่างสองโมเลกุลนี้เท่ากับ **1.000 พอดี** เนื่องจาก Morgan Fingerprints ที่ตั้งค่าตามปกติไม่บันทึกข้อมูลสเตอริโอเคมี แบบจำลองจึงได้รับเวกเตอร์คุณลักษณะที่เหมือนกันทุกประการสำหรับโมเลกุลสองตัวที่มีฤทธิ์ต่างกันมหาศาล และไม่มีทางทำนายทั้งคู่ให้ถูกต้องพร้อมกันได้

ข้อค้นพบนี้มีความสำคัญมากในบริบทของสารยับยั้ง M^pro เพราะสารกลุ่มนี้จำนวนมากมีลักษณะคล้ายเปปไทด์ซึ่งมีศูนย์กลางไครัลหลายตำแหน่ง และการจับกับโปรตีนขึ้นอยู่กับรูปทรงสามมิติอย่างมาก

## 5.4 ข้อจำกัดของการศึกษา

1. **เป็นการศึกษา In Silico เท่านั้น** ไม่มีการยืนยันผลในห้องปฏิบัติการ สารที่แบบจำลองทำนายว่ามีฤทธิ์แรงยังไม่ได้รับการทดสอบจริง
2. **SHAP แสดงความสัมพันธ์เชิงสถิติ ไม่ใช่กลไกเชิงสาเหตุ** โครงสร้างย่อยที่ระบุได้เป็นเพียงรูปแบบทางสถิติที่แบบจำลองเรียนรู้ ไม่ใช่การพิสูจน์ว่าโครงสร้างนั้นทำหน้าที่จับกับเอนไซม์จริง
3. **ข้อมูลมาจากหลายห้องปฏิบัติการและหลายโปรโตคอล** แม้จะกรอง assay เฉพาะ 3CL-Pro แล้ว แต่วิธีการวัด ความเข้มข้นของเอนไซม์ และชนิดสับสเตรตที่ต่างกันยังเป็นแหล่งความแปรปรวนในตัวแปรตาม
4. **คุณลักษณะไม่ครอบคลุมสเตอริโอเคมี** ตามที่อภิปรายในหัวข้อ 5.3.3 ซึ่งเป็นข้อจำกัดเชิงหลักการที่ส่งผลต่อความสามารถทำนายสารกลุ่มเปปไทด์คล้าย
5. **ความสามารถทำนายจำกัดอยู่ในปริภูมิเคมีของชุดฝึก** ตามที่พิสูจน์แล้วในหัวข้อ 5.3.1
6. **ไม่ครอบคลุม Molecular Docking และ Molecular Dynamics** ตามขอบเขตที่ประกาศไว้

## 5.5 ข้อเสนอแนะ

### 5.5.1 ข้อเสนอแนะสำหรับการนำผลไปใช้

1. **ใช้แบบจำลองเป็นเครื่องมือจัดลำดับความสำคัญ ไม่ใช่เครื่องมือวัดค่าสัมบูรณ์** เนื่องจากค่า Spearman ρ สูงกว่าที่ค่า R² บ่งชี้ การใช้แบบจำลองเพื่อเรียงลำดับสารก่อนนำไปทดสอบจริงจะให้ประโยชน์สูงสุด
2. **ตรวจสอบ Applicability Domain ก่อนใช้ทุกครั้ง** ควรคำนวณค่า Tanimoto สูงสุดต่อชุดฝึกก่อนเชื่อผลทำนาย หากต่ำกว่า 0.4 ควรถือว่าผลทำนายไม่น่าเชื่อถือ
3. **อ้างอิงค่า R² = 0.5127 จาก Scaffold Split** เมื่อสื่อสารความสามารถของแบบจำลองในการทำนายสารที่มีโครงสร้างแกนกลางใหม่

### 5.5.2 ข้อเสนอแนะสำหรับการพัฒนาต่อยอด

1. **เปิดใช้งานสเตอริโอเคมีในการสกัด Fingerprints** โดยตั้งค่า `includeChirality=True` ซึ่งจะช่วยแก้ปัญหาสเตอริโอไอโซเมอร์ที่พบในหัวข้อ 5.3.3 ได้โดยตรง คาดว่าจะเป็นการปรับปรุงที่ให้ผลตอบแทนสูงที่สุดเมื่อเทียบกับความพยายามที่ใช้
2. **แก้ปัญหาความไม่สมดุลของข้อมูล** ด้วยการเพิ่มน้ำหนักตัวอย่างสาร inactive ในฟังก์ชันสูญเสีย หรือรวบรวมข้อมูลสาร inactive เพิ่มเติมจากฐานข้อมูล PubChem BioAssay
3. **ทดลองใช้คุณลักษณะเพิ่มเติม** เช่น RDKit Descriptors ชุดเต็ม, MACCS Keys หรือ Pharmacophore Fingerprints เพื่อเพิ่มมิติของสารสนเทศ
4. **ทดลองใช้แบบจำลองที่เรียนรู้การแทนโครงสร้างเอง** เช่น Graph Neural Networks (GNN) ซึ่งรับโครงสร้างโมเลกุลเป็นกราฟโดยตรง และสามารถเข้ารหัสสเตอริโอเคมีได้
5. **สร้างแบบจำลองประมาณความไม่แน่นอน** เช่น Conformal Prediction หรือ Ensemble Variance เพื่อให้แบบจำลองสามารถบอกได้ว่าตัวเองไม่มั่นใจเมื่อใด ซึ่งจะช่วยลดปัญหาที่พบในหัวข้อ 5.3.1
6. **พัฒนาเว็บแอปพลิเคชันคัดกรองตัวยา** โดยรับ SMILES เป็นข้อมูลนำเข้า แล้วแสดงค่า pIC50 ที่ทำนาย พร้อมค่าความคล้ายคลึงต่อชุดฝึกเป็นตัวบ่งชี้ความน่าเชื่อถือ และภาพโครงสร้างย่อยที่มีอิทธิพลต่อการทำนาย

### 5.5.3 ข้อเสนอแนะเชิงระเบียบวิธีสำหรับงาน QSAR

1. **รายงานผลทั้ง Random Split และ Scaffold Split ควบคู่กันเสมอ** เพื่อให้ผู้อ่านเห็นภาพความสามารถทำนายที่แท้จริง
2. **ประเมินและรายงาน Applicability Domain เป็นส่วนหนึ่งของผลลัพธ์มาตรฐาน** ไม่ใช่การวิเคราะห์เสริม
3. **ตรวจสอบการซ้อนทับระหว่างชุดฝึกกับชุดทดสอบข้ามแหล่งด้วย InChIKey เสมอ** ในโครงงานนี้พบสารซ้ำ 4 ตัวซึ่งหากไม่ตัดออกจะทำให้ผลการทดสอบข้ามชุดข้อมูลไม่ถูกต้อง
4. **วิเคราะห์ค่าคลาดเคลื่อนแยกตามกลุ่มย่อย** ไม่ใช่รายงานเฉพาะค่ารวม เพราะค่ารวมอาจซ่อนจุดอ่อนเชิงระบบไว้ ดังกรณีสาร inactive ในโครงงานนี้
5. **ตรวจสอบผล SHAP ด้วยสถิติเชิงพรรณนาประกอบ** เช่น สัดส่วนการปรากฏของบิตในแต่ละกลุ่ม เพื่อป้องกันการตีความผิดพลาดดังกรณีบิต FP_807

### ก.3 โค้ดสำคัญ: Pipeline ป้องกัน Data Leakage

```python
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler

def make_pipe(estimator, fp_cols=FP_COLS, desc_cols=DESC_COLS):
    transformers = []
    if fp_cols:
        transformers.append(("fp", "passthrough", list(fp_cols)))
    if desc_cols:
        transformers.append(("desc", StandardScaler(), list(desc_cols)))
    prep = ColumnTransformer(transformers, remainder="drop")
    return Pipeline([("prep", prep), ("model", estimator)])
```

### ก.4 โค้ดสำคัญ: Scaffold Split

```python
from collections import defaultdict
from rdkit.Chem.Scaffolds import MurckoScaffold

def scaffold_split(smiles_list, test_frac=0.25):
    buckets = defaultdict(list)
    for i, s in enumerate(smiles_list):
        sc = MurckoScaffold.MurckoScaffoldSmiles(smiles=s, includeChirality=False)
        buckets[sc].append(i)
    groups = sorted(buckets.values(), key=len, reverse=True)
    n_train = len(smiles_list) - int(len(smiles_list) * test_frac)
    train, test = [], []
    for g in groups:
        (train if len(train) + len(g) <= n_train else test).extend(g)
    return np.array(train), np.array(test)
```
