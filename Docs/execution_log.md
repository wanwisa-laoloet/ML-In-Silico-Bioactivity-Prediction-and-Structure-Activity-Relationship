## สี่เรื่องที่ผลจริงต่างจากที่แผนคาด — รายงานตามตรง

**1. E5 ล้มเหลวในการพิสูจน์ leakage** ผลต่างแค่ +0.0001 R² เพราะ scaling กระทบเพียง 4 จาก 1,028 features ผมจึงเพิ่ม **E5b** จำลอง leakage แบบเดียวกับที่พบใน `xfinal.csv` (SelectKBest 300 features บนข้อมูลทั้งชุด) ซึ่งวัดอคติบวกได้จริง **+0.0116 R²** สรุปได้ว่า Pipeline เป็นความถูกต้องเชิงระเบียบวิธี แต่ leakage ที่อันตรายจริงในโครงงานนี้คือ feature selection ไม่ใช่ scaling

**2. External validation ล้มเหลว: R² = −1.72** (แย่กว่าทายค่าเฉลี่ย) พร้อม bias +1.19 log units สาเหตุวัดได้ชัด — **84.4% ของสาร DDH อยู่นอก Applicability Domain** (max Tanimoto < 0.4) เทียบกับชุดทดสอบภายในที่มีแค่ 7.6% แต่ **ρ = 0.52** ยังบอกว่าโมเดลจัดอันดับได้ระดับปานกลาง จึงใช้คัดกรองเบื้องต้นพอได้ แต่ห้ามอ่านค่า pIC50 เป็นตัวเลขสัมบูรณ์กับสารนอกโดเมน

**3. Ablation ชี้ว่า Lipinski เพิ่มค่าน้อย** — FP อย่างเดียว 0.5885 → Hybrid 0.5997 (+0.011) แต่ SHAP กลับพบว่า **MW เป็น feature อันดับ 1** และ Lipinski ติด Top-20 ครบทั้ง 4 ตัว สองผลนี้ไม่ขัดกัน: fingerprint เข้ารหัสข้อมูลขนาดโมเลกุลไว้แล้วบางส่วน Lipinski จึงสำคัญแต่ซ้ำซ้อน

**4. Scaffold split ต่ำกว่า random split มาก** (0.513 vs 0.703) — ยืนยันความเสี่ยง R4 ในแผนว่า random split ให้ตัวเลขสูงเกินจริง ตัวเลขที่ควรอ้างเวลาพูดถึงการทำนายสารแกนโครงสร้างใหม่คือ **0.513**
